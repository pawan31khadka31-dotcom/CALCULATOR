Rhombus = ½ d₁ d₂
Trapezoid = ½ (a+b) h

Linear algebra / रेखीय बीजगणित
2×2 determinant: |a b; c d| = ad − bc
2×2 inverse: 1/(ad−bc) × [d −b; −c a]
3×3 determinant: a(ei−fh) − b(di−fg) + c(dh−eg)
Inverse: A⁻¹ = adj(A) / det(A)
det(AB) = det A × det B; det(Aᵀ) = det A
det(kA) = kⁿ det A (n×n matrix)
(AB)ᵀ = BᵀAᵀ; (AB)⁻¹ = B⁻¹A⁻¹
Product: (AB)ᵢⱼ = Σ aᵢₖ bₖⱼ
Solve Ax = b: x = A⁻¹ b
Cramer's rule: xᵢ = det(Aᵢ) / det(A)
Eigenvalues: det(A − λI) = 0, Av = λv
Sum of eigenvalues = trace; product = det
2×2 characteristic equation: λ² − (trace)λ + det = 0
Dot product: a·b = Σ aᵢbᵢ = |a||b| cos θ
Cross product: a×b = (a₂b₃−a₃b₂, a₃b₁−a₁b₃, a₁b₂−a₂b₁), |a×b| = |a||b| sin θ
Length: |a| = √(Σ aᵢ²)
Projection of a on b = (a·b / |b|²) b
Rank + nullity = number of columns
Trigonometry / त्रिकोणमिति
sin²θ + cos²θ = 1
1 + tan²θ = sec²θ; 1 + cot²θ = csc²θ
tan θ = sin θ / cos θ; cot θ = 1/tan θ
sec θ = 1/cos θ; csc θ = 1/sin θ
sin(−θ) = −sin θ; cos(−θ) = cos θ
sin(90°−θ) = cos θ; cos(90°−θ) = sin θ
sin(A±B) = sinA cosB ± cosA sinB
cos(A±B) = cosA cosB ∓ sinA sinB
tan(A±B) = (tanA ± tanB) / (1 ∓ tanA tanB)
sin 2A = 2 sinA cosA
cos 2A = cos²A − sin²A = 2cos²A − 1 = 1 − 2sin²A
tan 2A = 2 tanA / (1 − tan²A)
sin²A = (1 − cos 2A)/2; cos²A = (1 + cos 2A)/2
2 sinA cosB = sin(A+B) + sin(A−B)
2 cosA cosB = cos(A+B) + cos(A−B)
2 sinA sinB = cos(A−B) − cos(A+B)
